# Contributing

Use English for source identifiers, comments, documentation, issues, pull requests and commits. User-facing translations are welcome.

Work on a topic branch and open a pull request. Keep upstream revisions pinned and preserve copyright/license files. Explain the behavioral change, validation performed and remaining physical-test requirements.

Never edit generated `.build/` sources as the only copy of a change. Update the checked-in overlays or preparation script, regenerate, and test again. Do not commit keys, signing identities, personal provisioning profiles, local SDK paths or credentials.

Original Roma code is GPL-3.0-or-later. Third-party files retain their original terms; contributions must not relabel them.
